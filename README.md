# playlistDownload
A very small simple bash script that downloads music in the best format available using yt-dlp with cover art.


## How to use this

Make sure that yt-dlp is installed if it isn't download it from the official repository.
Set yt-dlp as a environment variable in linux. 


Copy the link of the playlist of music you want to download.
Run the bash script paste the link and then enter the name of the playlist you want to make (to make sure the music is easy to navigate). Press Enter. 

It would start the download let it finish.
